鮫暦AI、五つの入口。

元の浮世絵・家紋・写真を使い、ファーストビューの構図を変えた5案です。各案を開くと、その下に共通のサイトマップと、神子元島・アカシュモクザメの紹介が続きます。

1. 浮世絵の帯

浮世絵全体を一枚の絵として見せ、縦の題字を添える。元の世界観を最も生かす案。

この案を実際のサイズで見る

2. 水面の余白

青い水中写真と大きな題字。余白の下に群れが広がる、開放的な入口。

この案を実際のサイズで見る

3. 島から潜る

灯台と水平線を主役に、海上から水中へ。初めて訪れる人にも神子元という場所が伝わる案。

この案を実際のサイズで見る

4. 暦の扉

家紋と題字を静かに据え、隣に浮世絵を広げる。和の暦を開くような落ち着いた構成。

この案を実際のサイズで見る

5. 群れの中へ

題字と短いコピーを写真から分離し、群れの写真を大きく見せる。水中の臨場感を優先する案。

この案を実際のサイズで見る

トップページには案4「暦の扉」を採用しました。家紋・題字と浮世絵を分けた構成です。ほかの案も比較用に残しています。
